# 노션 투두 위젯 (Notion Todo Widget)

## 소개

노션(Notion) 투두리스트 데이터베이스를 안드로이드 홈화면 위젯으로 표시하는 앱입니다.
노션 네이티브 위젯은 페이지 링크만 제공하지만, 이 앱은 실제 할 일 목록을 홈화면에서 바로 확인하고 체크할 수 있게 해줍니다.

## 주요 기능

- **아이젠하워 매트릭스** — 중요+긴급 / 중요+비긴급 / 비중요+긴급 / 비중요+비긴급 4사분면으로 할 일 분류
- **실시간 동기화** — 노션 API 연동, 15분 간격 자동 동기화 + 수동 동기화
- **마감일 D-day 표시** — 2주 이내 마감 항목에 D-day 배지 표시 (D-3 이하 빨강 / D-4~7 주황 / D-8~14 회색)
- **마감일 정렬** — 각 사분면 내 마감일 오름차순 정렬, 미설정 항목은 하단 표시
- **체크 기능** — 위젯에서 항목 체크 시 노션에서 완료 처리
- **취소선 모드** — 체크 시 즉시 제거 또는 취소선 표시 선택 가능. 취소선 항목 재클릭 시 노션에서 시작 전으로 복원
- **스크롤** — 각 사분면 내 항목 스크롤 가능
- **투명도 조절** — 위젯 배경 투명도 / 사분면 배경 투명도 각각 설정
- **노션 연결** — 사분면 라벨 탭 시 노션 DB 페이지 열기, 위젯 타이틀 탭 시 앱 열기

## 노션 DB 속성 설정

앱 사용 전 노션 데이터베이스에 아래 속성을 추가해야 합니다.

| 속성명 | 타입 | 값 |
|---|---|---|
| 이름 | Title | 할 일 제목 |
| 상태 | Status | 시작 전 / 진행 중 / 완료 |
| 우선순위 평가 | Select | 중요+긴급 / 중요+비긴급 / 비중요+긴급 / 비중요+비긴급 |
| 마감일 | Date | 날짜 |

## 사용 방법

1. **APK 빌드**
   - Android Studio에서 프로젝트 열기
   - `Build` → `Generate App Bundles or APKs` → `Generate APKs`
   - `app/build/outputs/apk/debug/app-debug.apk` 파일을 폰으로 전송 후 설치

2. **노션 API 토큰 발급**
   - [notion.so/my-integrations](https://www.notion.so/my-integrations) 접속
   - 새 연동 만들기 → 토큰 복사
   - 노션 투두 DB 페이지 → `···` → 연결 → 만든 연동 추가

3. **데이터베이스 ID 확인**
   - 노션에서 투두 DB를 전체 페이지로 열기
   - URL에서 `notion.so/` 뒤 32자리 코드 복사

4. **앱 설정**
   - 앱 실행 → API 토큰 + 데이터베이스 ID 입력
   - 저장 및 연결 테스트 → 성공 확인

5. **위젯 추가**
   - 홈화면 빈 곳 길게 누르기 → 위젯 → 노션 투두 위젯 추가
